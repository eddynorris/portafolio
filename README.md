# Portafolio de Eddy Orosco

Portafolio web estático de Eddy Orosco Prada (Ingeniero de Software y Analista de Videojuegos). Sitio de una sola página con dos modos de visualización: "Ingeniero" (perfil profesional, habilidades técnicas y proyectos) y "Esports" (trayectoria como jugador profesional y capitán de equipos de Dota 2).

## Características principales

- Diseño one-page con tema cyberpunk y sistema de transiciones animadas entre modos (Engineer / Esports).
- Perfil profesional: servicios, estadísticas y habilidades técnicas interactivas (hexágonos de habilidades).
- Sección de proyectos destacados (Manngo J&K, RUWAYTECH, CODIDEEP).
- Perfil esports: historia, equipos profesionales y logros.
- Formulario de contacto, botón de WhatsApp, scroll to top y widget de asistente (IA próximamente).
- Descarga de CV.

## Tecnologías usadas

- HTML5, CSS3 y JavaScript (vanilla).
- Font Awesome y Google Fonts (Orbitron, Inter).

## Requisitos previos

- Navegador moderno. No requiere build ni dependencias.

## Cómo ejecutar

Abrir `index.html` directamente en el navegador, o servir la carpeta con un servidor estático, por ejemplo:

```bash
python -m http.server 8080
```

y abrir `http://localhost:8080`.

## Estructura del proyecto

- `index.html` — estructura del sitio.
- `styles.css` — estilos y temas.
- `script.js` — lógica de modos, transiciones e interactividad.
- `image.png` — avatar principal.
- `noping.png`, `infinity.png`, `estarbacks.png` — logos de equipos esports.
